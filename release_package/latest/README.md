Verify with `SHA256SUMS.txt` (`sha256sum -c SHA256SUMS.txt`).

**Spindle Standard** binaries were withdrawn from the repository. v1.6.0 shipped a Studio unlock that could be bypassed with publicly known tokens and has been superseded by the source tree (`v1.7.0-STUDIO` plus security fixes). New Standard builds are published only as signed GitHub Release assets: <https://github.com/manaphassan/Spindle/releases>.
Debug builds are never distributed.
