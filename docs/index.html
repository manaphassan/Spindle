Get Started

Install Spindle via ADB onto any Android 8.0+ device or dedicated DAP.

# 1. Clone the repository
git clone https://github.com/manaphassan/Spindle.git
cd Spindle

# 2. Compile debug APK
./gradlew assembleDebug

# 3. Install to connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 4. Launch Spindle Home
adb shell am start -n com.hana.spindle.debug/com.hana.spindle.ui.MainActivity
