Get Started

Install Spindle via ADB onto any Android 8.0+ device or dedicated DAP.

# 1. Clone the repository
git clone https://github.com/manaphassan/Spindle.git
cd Spindle

# 2. Compile optimized release APK (4.8 MB with R8 & ProGuard)
./gradlew assembleRelease

# 3. Install to connected device or DAP
adb install -r app/build/outputs/apk/release/app-release.apk

# 4. Launch Spindle Home
adb shell am start -n com.hana.spindle/com.hana.spindle.ui.MainActivity
