## What's Changed

### 🏷️ Generic cassette shell names
The classic deck's cassette shells no longer use real tape brand names. Their looks and colours are unchanged.

| Shell button | Shell name | Printed label |
| :--- | :--- | :--- |
| PURE METAL (default) | Pure Metal Type IV | PURE METAL • TYPE IV |
| HIGH BIAS | Type II High-Bias | HIGH BIAS 90 • TYPE II |
| AMBER GOLD | Type II Amber Gold | AMBER GOLD 90 • TYPE II |
| CHROME | Anthracite Chrome | ANTHRACITE CHROME • TYPE II |
| GOLD HIGH | Gold High Position | GOLD HIGH 100 • TYPE II |

Your selected shell is migrated automatically on first launch.
