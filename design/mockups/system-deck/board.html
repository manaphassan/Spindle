what changes

  1. Third panel of the same machine. Same band, brushed body, smoked window and switch skin as the tape and radio decks. Only shown when the deck style is a Walkman colorway; Classic keeps the Zune pages.
  2. FUNCTION switch replaces the rotating pivot. SOUND · SETTINGS · APPS stay in fixed positions (the new order) and the knob shows where you are. Swiping between them still works.
  3. Sound: display vs controls. The response curve and FX chain are read-outs, so they sit in the window. Things you touch (10 faders, LOW/MID/HI/FILTER, volume, BYPASS/SATURATION/CROSSFEED) are hardware on the chassis. Same controls, same data.
  4. No duplicate tape switches. TAPE EQ and DOLBY NR already live on the tape deck, so the sound page doesn't repeat them.
  5. Settings is an LCD menu. 51dp rows, number, title and summary; the selected row inverts. Sub-pages open in the same window with BACK returning to the menu.
  6. Apps in the window. Search on an LCD strip, A–Z as a real key, and a letter rail with the radio's tangerine needle.
  7. Contrast holds. Butter on glass, print on silver and stone on black all clear WCAG AA at these sizes.P0
  8. Scope. Sound needs the EQ, knob and VU views recoloured from green to the colorway; the rest is reskinning existing layouts. Lower sound sections (VU, curves, presets) scroll inside the page.
